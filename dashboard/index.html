How implied value is computed

Every row is scored by one function of the snapshot's own figures. No protocol name is special-cased, and no row is hand-picked.

implied = round( tvl_usd × multiple × growth multiplier × maturity multiplier )
multiple
The median market-cap-to-TVL ratio of the live-token protocols in the same category, computed from this snapshot itself, when the category holds at least three of them; otherwise the market-wide median. Capped at 1.0, so no implied value exceeds the protocol's own TVL.
growth multiplier
1 + clamp(change_7d, −60, 120) / 100 × 0.5. Unreported growth counts as 0.
maturity multiplier
0.6 + 0.4 × √(min(age_days, 1095) / 1095). Tenure matters most in the first year: the premium rises steeply while a protocol proves it survives, then saturates. An unknown age uses 365 days.

For the judge: the multiple is calibrated from the snapshot's own live-token protocols — the table above is the whole calibration, with sample sizes. The page recomputes every row's implied value from the same figures; open any protocol's detail view and the check is shown against the number board.json carries. The Set aside tab lists every pre-token protocol the board left out, with its reason.

Implied value is a model, not a price: it says what a token would be worth if the protocol's record stayed as it is. It does not predict whether or when a token is issued. Snapshot: DefiLlama protocol index, fetched once and sealed. No network: every number on this page comes from the snapshot beside it.
